# SUJ PROJECT

Starter project Android native (Kotlin) dengan tema ungu neon.

## Fitur versi awal
- Template XML contoh (template dasar)
- Import XML melalui pemilih dokumen Android
- Pilih foto dari galeri
- Export isi proyek sebagai file XML

## Cara membuat APK
1. Instal Android Studio pada komputer/laptop.
2. Buka folder `SUJ_PROJECT` melalui Android Studio.
3. Tunggu Gradle Sync selesai. Pastikan Android SDK 35 terpasang.
4. Pilih **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
5. APK debug dapat ditemukan di `app/build/outputs/apk/debug/app-debug.apk`.

## Catatan
Ini adalah fondasi aplikasi versi 1.0. Import/ekspor saat ini menangani teks XML umum; belum mengonversi XML menjadi proyek CapCut atau Alight Motion secara otomatis. Untuk kompatibilitas aplikasi tertentu, diperlukan format XML resmi/contoh proyek yang sesuai.
